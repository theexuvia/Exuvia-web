2. Qué datos se recogen y para qué

El formulario puede recoger tu nombre, dirección de correo electrónico, motivo del mensaje, asunto y contenido del mensaje. Estos datos se utilizarán para leer, gestionar y responder a tu consulta o propuesta y, cuando proceda, continuar la conversación relacionada con una posible colaboración.

3. Base jurídica

La base jurídica aplicable deberá determinarse en función del tipo de comunicación y documentarse antes de publicar la web. Para consultas relacionadas con una posible colaboración pueden resultar aplicables las medidas precontractuales solicitadas por la persona interesada; para otras consultas habrá que confirmar la base correspondiente. No se utilizarán estos datos para enviar comunicaciones comerciales no solicitadas.

4. Conservación y destinatarios

Los datos se conservarán durante el tiempo necesario para gestionar la consulta y, después, durante los plazos que puedan resultar exigibles por obligaciones legales. El formulario está diseñado para procesarse mediante Netlify Forms cuando la web se publique en Netlify; revisa sus condiciones y el tratamiento de datos aplicable antes de activar el formulario.

5. Tus derechos

Puedes solicitar el acceso, rectificación, supresión, oposición, limitación del tratamiento y, cuando corresponda, portabilidad de tus datos escribiendo a exuvia.info@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos si consideras que el tratamiento no se ajusta a la normativa.

6. Seguridad

No incluyas datos especialmente sensibles ni información personal de terceras personas en el formulario. Esta página es una base de trabajo y no sustituye una revisión legal de la política de privacidad definitiva.
